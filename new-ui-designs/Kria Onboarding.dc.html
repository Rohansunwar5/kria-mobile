KRIA · ONBOARDING

From download to first match in under two minutes.

Each phone is one step, and every field is live. It ends on the new-player Home.

Exactly the player-auth API

Register (first name, last name, email, phone) → verify the emailed OTP → set a password (8+ characters). Log in by password or by emailed code. Google sign-in skips straight to the profile. Status goes pending → otp_verified → verified.

Profile after the account, never before

Sport and city personalise Home. Date of birth and gender are only needed to enter tournaments, so they're skippable with the consequence stated. The notifications screen comes last and only explains what it's for.
