# KRia icon set

73 glyphs, 24x24, stroke 2, square caps, mitred joins.

- `svg/` — one file per icon (`kria-<name>.svg`), stroke set to `currentColor`
- `kria-icons-sprite.svg` — all glyphs as `<symbol>`; reference with `<use href="#kria-gavel">`
- `KriaIcons.jsx` — react-native-svg components, `<IconGavel size={24} color="#F97316" />`
