Easing — two curves, no more
Easing.out(Easing.cubic)
Anything that arrives or responds: reveals, presses, focus, fades. Fast off the mark, settles soft. CSS: cubic-bezier(0.16,1,0.3,1).
Easing.inOut(Easing.cubic)
Anything that loops or travels: sweeps, drift, pulse. Symmetrical, so a reversing repeat has no seam.
No springs, no linear. Springs overshoot, and overshoot fights hard edges and 1.5px borders — the whole point of this system is that nothing is soft. Linear only ever reads as a progress bar.
Rules
One moving thing per card. Reveal, or drift, or shimmer — never two. A list where every row breathes is a list nobody can read.
Never animate the seeded hue. It is identity, not decoration: the same tournament must be the same colour on the card and on its detail screen.
Never animate height or layout in a list. Only opacity, transform and clipPath — the three the UI thread can carry without a re-layout.
Idle animation stops off-screen. cancelAnimation() on blur and on viewability change, or the drift keeps costing battery behind a screen nobody is looking at.
Honour reduce-motion. AccessibilityInfo.isReduceMotionEnabled(): reveals become instant, ambient drift does not run at all. The design must be complete with every animation off — and it is, because the seeded hue and the banner do the differentiating.
