Why. The 115° band is already in the system, so the empty ground gets texture from the family it belongs to rather than a new effect. Three cards, three hues, three offsets: the strip reads as alive without any two looking alike.
Cost. This is motion standing in for missing data. It runs on every banner-less card forever, and it makes the absent banner more conspicuous, not less. The hue seeding alone already differentiates these grounds, so organiser banner upload is still the better spend.
Shipped as one skewed gradient band, not a hairline field. The CSS version here is a repeating gradient; in React Native that means 200 clipped views per card, which is unacceptable in a list. One skewed LinearGradient at the same 115° carries it for a single view. Banner-less grounds only, and it stops on screen blur.
